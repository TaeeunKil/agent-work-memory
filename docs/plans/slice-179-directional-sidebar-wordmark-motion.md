# Slice 179 - Directional sidebar wordmark motion

## Intent

Make the stable Agent Work Memory wordmark feel generated by the sidebar's
expansion rather than merely appearing after it. Preserve the no-reflow fix
from slice 178.

## Motion shape

```text
expand:   left origin + clipped + 92% scale -> revealed + 100% scale
collapse: revealed + 100% scale -> left origin + clipped + 92% scale

Agent Work  ----- first
Memory       ----- follows 25ms later
```

## Work

1. Give each visual wordmark line its own element while keeping the link's
   existing accessible name.
2. Animate opacity, left-origin scale, horizontal clipping, and a small
   directional translation without changing layout dimensions.
3. Stagger the second line slightly on expansion; collapse both promptly.
4. Keep the repository's reduced-motion override authoritative.
5. Update the viewer asset contract and visually verify both end states.
